## 🧩 Sobre o Projeto

Este projeto utiliza a biblioteca **OpenCV** para abrir uma imagem, exibi-la originalmente e depois convertê-la para **escala de cinza**.

Também é exibido no terminal o array 2D contendo os valores dos pixels da imagem em tons de cinza.

---

## 🧰 Tecnologias Utilizadas

* **Python**
* **OpenCV (cv2)**

---

## ⚙️ Funcionalidades

* 📷 Leitura de uma imagem;
* 🖼️ Exibição da imagem original;
* ⚫ Conversão para escala de cinza;
* 🔢 Exibição dos pixels em um array 2D;
* ⏸️ Permanência das janelas abertas até uma tecla ser pressionada.

---

## 📚 Aprendizados

* Utilização da biblioteca **OpenCV**;
* Leitura de imagens com `cv2.imread()`;
* Exibição de imagens com `cv2.imshow()`;
* Conversão de cores com `cv2.cvtColor()`;
* Representação de imagens como arrays de pixels.

---

## 🕹️ Como Executar

1. Instale o OpenCV:

```bash
pip install opencv-python
```

2. Coloque a imagem `butterfly.jpg` na mesma pasta do programa.

3. Execute o arquivo Python:

```bash
python main.py
```
